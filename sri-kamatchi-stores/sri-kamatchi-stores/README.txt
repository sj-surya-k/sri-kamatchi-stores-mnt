SRI KAMATCHI STORES WEBSITE

HOW TO OPEN
Double-click index.html. It opens in your browser. No internet or server needed.

HOW TO CHANGE PRICES
1. Right-click index.html > Open with > Notepad (or VS Code).
2. Find the list that starts with:  var P=[
3. Each line looks like:  ["Rice","🍚","Groceries",60,"per kg"]
   Change the number (60) to the new price. Use null instead of a number to show "Ask in store".
4. To add an item, copy a line and change the name, emoji, category and price.
5. Save the file and refresh the browser.

OTHER THINGS TO EDIT (also in index.html)
- WhatsApp number: search for WHATSAPP (use 91 + number, no spaces)
- Address, phone numbers and hours: search for "Visit us"

HOW TO PUT IT ONLINE
Upload the whole folder to any static host (Netlify, GitHub Pages, Cloudflare Pages) or to your hosting's public_html folder.
